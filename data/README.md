# data/ — только локально

Всё, кроме этого файла, в git не попадает (см. `.gitignore`).

```
data/videos/            .mov из датасета
data/labels_clean.csv   разметка (передаётся внутри команды офлайн, не через git)
data/frames_around/     кадры для разбора
```

Датасет используется только в рамках хакатона. Запрещено выкладывать видео, кадры, разметку
и результаты по ним в открытый доступ и в облака: GitHub, Google Drive/Sheets, Dropbox, iCloud,
облачные мессенджеры. Сами видео и кадры не загружаем ни в какие облачные AI/OCR/CV-сервисы.
По регламенту можно словами описывать происходящее на видео (например, при обсуждении с AI-ассистентом).
Передача внутри команды — флешка или локальная сеть (LocalSend, scp, общая папка в LAN).
После хакатона — удалить.
